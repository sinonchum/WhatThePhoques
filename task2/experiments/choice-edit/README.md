# 第三版离线实验

公开基线为第二轮提交的 0.10。本目录的 [CSV](formal/candidate.csv) 复用了 660 条正式回答。新增查询为 0，以下指标均为离线测量。

## 练习端点

[choice_edit.py](../../choice_edit.py) 在上一版每个端点的分组投票上，增加一个可观测的格式信号。端点复述选项时改变选项字母后的分隔符、在复制的选项后追加句号，或在数字后追加句号和解释，都会产生证据。同一题内对证据取中心值，再按原先的上三分位数划分变体。

每格为 2048 次重放中 model MCC 严格超过 0.65 的次数。同一列的新旧方法使用完全相同的题目和回复，已核对抽样摘要。[完整记录](practice.json)

| 种子 | 分层抽题，旧 → 新 | 固定难题，旧 → 新 |
|---|---:|---:|
| 519883 | 1538 → 1638 | 880 → 1113 |
| 731029 | 1547 → 1637 | 831 → 1082 |
| 7241831（新增） | 1530 → 1647 | 909 → 1117 |

新增种子的分层过线率为 80.4%，固定难题为 54.5%。三个种子共用同样的九个端点，开发期间也看过它们的输出。用正式两轮的二十道题再做 1024 次练习重放，新方法把弱 LoRA 与原版误合并了 4 次（旧版 9 次），把 FP8 与原版误合并了 1023 次（旧版 1020 次）。仅使用这个格式改动，正式分组与旧提交完全一致。

另试过用正则化线性模型学习回答首尾与标点的 n-gram。每个待测练习端点及其所在的十题题块均从该次拟合中排除。种子 519883 的分层重放只有 13 / 2048 次过线，和基线投票融合后为 209 / 2048 次，均未采用。

## 正式候选 CSV 的变化

G1、G2 的单词或单数字回复分别占 97.7% 和 96.4%。为这些家族增加一个候选算法：逐题统计每个答案在同家族其他端点中出现得多不多，再合并一个端点在不同题上的稀有程度。选方法时把二十道正式题反复拆成题型均衡的两半，衡量两半各自产生的同模型判断的一致性。抽样 256 次，共用这二十道题。相关系数无定义的分组在选择时计 0。[各家族的测量](formal/agreement.json)

只在 G2 选中了按答案取值比较的方法。G2 的分半一致性中位数从 0 到 0.153；独立采集的前后两轮也只有 0.153。此次更改将 ep-07、ep-08 移出核心组，将 ep-28、ep-30 移入核心组，合计改变 528 对中的 22 对。正式端点没有公开真值，这 22 对的正确率未知。练习分数只评估上述格式算法；G2 的方法是根据无标签正式回答选出的。

## 复现

在仓库根目录执行以下命令。正式候选输出到一个新的目录，方便和快照逐字节比较。

```bash
python3 task2/replay.py --solver choice_edit --seed 7241831
python3 task2/replay.py --solver choice_edit --seed 7241831 --protocol fixed-hard
python3 task2/compare_panels.py --out task2/runs/choice-edit-reproduction
cmp task2/runs/choice-edit-reproduction/candidate.csv task2/experiments/choice-edit/formal/candidate.csv
```
