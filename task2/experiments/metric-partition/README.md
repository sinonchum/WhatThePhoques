## 分数怎样变化

家族项占 10%，在所有被评分的端点对上计算。模型项占 90%，只计**真实同一家族**的端点对，所有这样的对子一起算一次 MCC。两个子项都将负 MCC 截为零。我们冻结三个推测家族，每组 11 个，因此离线正式代理目标覆盖 165 对；真实家族及公开评分子集均未知。

设 N 为计入的对子数，P 为真实同模型对子数，K 为预测同模型对子数，TP 为交集大小。MCC 的分子可以写为 N×TP−P×K，分母为 √(P(N−P)K(N−K))。分母为零按零分处理。合并两个大小为 a、b 的组，会一次把 a×b 对由不同改成相同。实现按整份分组计分，保证相等关系具有传递性。

## 有标签的练习对照

选择格式信号权重时，一共比较 144 种设置，开发目标为两个不相交十题块中较小的平均 MCC 增益。两个题块分别为首轮十题和固定难题，各重放 512 次。冻结参数后换种子 1493807，与上一版格式算法使用相同回答，每个协议重放 2048 次。第三块留出题没有参与这轮拟合，历次实验曾用过这些题。九个练习端点均来自同一个基座。

| 题目 | 原版 → 新版平均模型 MCC | 严格超过 0.65 的次数，原版 → 新版 |
|---|---|---|
| 五类分层抽题 | 0.6404 → 0.6377 | 1649 → 1655 |
| 固定难题（换回答重放） | 0.5022 → 0.5168 | 1050 → 1141 |
| 留出十题 | 0.7328 → 0.7314 | 2044 → 2034 |

难题的平均误合并由 7.16 降至 6.82 对，平均误拆分由 1.73 降至 1.69 对。仍保留上一版作为整体基线。三个协议共享端点，重放次数不能替代独立家族数。[开发选择](grid.json) · [分层重放](grid-stratified.json) · [困难题](grid-fixed-hard.json) · [留出题](grid-holdout.json)

## 无标签的正式分组搜索

逐题重采样形成两种假设，一种依据回答格式，另一种依据答案内容距离做平均链接聚类。后者允许一个家族包含多个非单例组。再从这些分组及其共现矩阵的树切分中构造候选，跨家族合并对子，计算每份候选相对于各假设的截断 MCC。

全量搜索比较了 117260 份不同的候选分组，此为候选池的笛卡尔积。最大化混合假设下平均 MCC 的解与已提交的 0.10 版在全部 528 对上完全一致。第二个目标对格式、内容、混合三种证据分别求候选池最优值，再选最大落差最小的分组。由此产生此次上传的 16 对变化。按相同输入重新运行上榜基线作对照，用第一轮拟合、第二轮代理证据评价时，混合代理 MCC 由 0.242 到 0.301；反方向由 0.188 到 0.267。公开回执显示这两项代理改善未转化为可见的公开分提升。[假设与逐轮指标](formal.json) · [按混合目标得到的重复解](mixed.csv)
